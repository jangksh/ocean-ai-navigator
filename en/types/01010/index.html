How the Turtle type is built (01010)

The code lists Openness, Conscientiousness, Extraversion, Agreeableness and Emotional Stability in that order. A score at or above 50% is 1; below 50% is 0. High dimensions: Conscientiousness, Agreeableness. Low dimensions: Openness, Extraversion, Emotional Stability.
